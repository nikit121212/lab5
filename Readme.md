1. Дайте определение списка в языке программирования Python. Приведите 
примеры списков? 
Определение списка в Python:
Список (list) — это упорядоченная изменяемая коллекция элементов произвольных типов, заключённая в квадратные скобки.
Примеры: [1, 2, 3], ["a", "b", "c"], [1, "hello", 3.14, True]
2. Как можно обратиться к элементу списка в языке программирования Python?
Обращение к элементу списка:
По индексу: my_list[0] — первый элемент, my_list[-1] — последний.
3. Для чего используется срез при работе со списками в языке Python? 
 Срез (slice) при работе со списками:
Срез используется для получения части списка. Синтаксис: my_list[start:stop:step]. Например, my_list[1:4] вернёт элементы с индексами 1, 2, 3.
4. Какие основные встроенные функции для работы со списками в языке Python вы 
можете назвать? 
 Основные встроенные функции для работы со списками:
len(), max(), min(), sum(), sorted(), list(), range()
5. Какие основные операторы языка Python вы использовали при решении задач 
лабораторной работы? 
Основные операторы Python, использованные в задачах:
Арифметические: +, -, *, **, %
Сравнения: ==, !=, <, >, <=, >=
Логические: and, or, not
Принадлежности: in, not in
Присваивания: =, +=
6. Какой функцией надо воспользоваться для подсчёта количества элементов с 
данным значением в списке?
 Функция для подсчёта количества элементов с данным значением:
Метод .count() — my_list.count(значение) возвращает количество вхождений элемента в список.
